# 8‑week plan · Strategy B — clear the 0s, one large topic at a time

An **alternative** to [`weekly-plan.md`](weekly-plan.md) (which did quick‑wins first). Here the driver is
the **46 questions scored 0** ("nothing"). They're grouped into **large coherent topics**, tackled
**biggest‑first**. The shaky **1s** aren't their own week — they get **swept up** while you're already on
that topic. Same rhythm: self‑study in the week → **2 h** discuss & re‑score in the tool. Read locations
are in [`study-references.md`](study-references.md).

## How to run each topic block
1. **Read** the block's sections (see the table + `study-references.md`) — the on‑level **Cambridge Stage**
   sections are best for the qualitative topics (optics especially); **NCERT/Siyavula** for the
   quantitative Grade‑9 items (F=ma, Ohm's law, KE/PE, v=fλ, the atom).
2. **Practice** with the matching **CK‑12 worksheets** (answers in CK12WB ch26) and the tool's *Practice problems*.
3. In the **2 h**, have him explain the block back **in English**, work 2–3 problems, then **re‑score every
   0 (and swept 1) in that block** in the tool — you want to see 0→1 and 0→2 across a whole topic.

## Notes
- **Prefer whole topics:** finish a block before moving on, even if it spills a few days — coherence beats
  breadth here, which is the point of this strategy.
- **Reorder freely:** if you'd rather start with **Electricity** or **Optics** (self‑contained, satisfying to
  complete), swap the order — the blocks are independent.
- The heavy quantitative Grade‑9 items (Ohm's law, F=ma, KE/PE, v=fλ) are really Grade‑10 content — aim for
  first understanding, not mastery.
